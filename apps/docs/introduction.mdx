## Setting up

Franceschini Email is a private transactional email dashboard built on useSend. Sign in with your authorized GitHub account to manage emails, domains, API keys, suppressions, and webhooks. Public signup and waitlists are not used.

The API base URL is `https://franceschini.email/api`. These guides retain the upstream SDK package names and API headers for compatibility; configure SDKs to use `https://franceschini.email` instead of the hosted useSend service.

PostgreSQL stores application data and background jobs. Templates, the visual
editor, and image uploads have been removed, so MinIO/S3 storage is not required.
Supply a subject and HTML or text directly when sending, including batch sends.
Unknown request fields, including the retired `templateId` and `variables`,
are rejected. Inline base64 attachments remain supported without object storage.

Contacts, contact books, campaigns, subscription confirmation, and campaign
unsubscribe pages and APIs are not available in this installation. Existing
database records are retained for history; no campaign, contact-import, or
marketing-send workers run. Transactional batch sending and scheduled emails
remain supported, and the configured SES send rate is used entirely for
transactional delivery.
